# Stash ad kit

Everything here is generated by `build.py`. To change copy or colours, edit the script and rebuild:

```bash
uv run marketing/build.py             # everything (needs Google Chrome + ffmpeg, about 2 minutes)
uv run marketing/build.py --no-video  # SVG + PNG only
uv run marketing/build.py --explainer # only the narrated explainer videos
```

It also writes the link-preview image `frontend/public/og.png` (+ `og.svg`), which `index.html` points to.

## Files

| Placement | Size | Files |
|---|---|---|
| Instagram / Facebook Reels, Stories, TikTok, Shorts | 1080×1920 (9:16) | `png/reel-*.png`, `video/reel-stash-18s.mp4` |
| Instagram feed (shows largest) | 1080×1350 (4:5) | `png/feed-*.png` |
| YouTube, Facebook in-stream, X, LinkedIn video, website | 1920×1080 (16:9) | `png/landscape-*.png`, `video/landscape-stash-18s.mp4` |
| Link ads (Facebook, LinkedIn, X) and link previews | 1200×628 | `png/link-*.png`, `frontend/public/og.png` (1200×630) |
| Instagram / Facebook Stories | 1080×1920 | `png/story-*.png` (ask, canvas, remind, launch) |
| LinkedIn post | 1200×1200 | `png/linkedin-*.png` (ask, canvas, remind, launch) |
| LinkedIn profile cover | 1584×396 | `png/linkedin-cover.png` |

Every PNG has a matching SVG in `svg/` with the Geist font embedded, so it looks the same anywhere and scales to any
size. `svg/*-animated.svg` are the sources of the videos (they animate in a browser).

Reels keep all text out of the top 220 px and the bottom ~400 px, where Instagram draws its own buttons and caption.
Stories keep the top 250 px (progress bar, profile) and the bottom 340 px (reply bar) clear, and leave an empty band
under "Tap the link to try it free" at about y 1580–1660: put the **link sticker** there when posting. The LinkedIn
cover keeps its bottom-left corner empty, where LinkedIn places the profile photo.

The videos run 18 seconds at 30 fps (H.264 + AAC, `faststart`) and carry their own soundtrack, loudness-normalised to
-14 LUFS like Instagram, TikTok and YouTube. `soundtrack.py` synthesises it from scratch, so it is original and free
to use anywhere: a 120 BPM track in A minor with a quiet build, a riser into a beat drop when the product appears, a
whoosh on every cut, pops as cards land, a chime for the reminder notification and a resolving chord on the end card.
The scenes change on the bar lines at 0, 4, 8, 12 and 15 s. `audio/stash-theme-18s.m4a` is the track on its own,
for swapping the music in an editor or using it elsewhere. To use a trending Instagram sound instead, lower the
original audio to 0 in Instagram's editor.

## Explainer (narrated, 44 s)

A separate, longer version that explains the product with a female voiceover and on-screen captions (most Reels are
watched muted). The short ads above stay as they are.

| Placement | Size | File |
|---|---|---|
| Reels, Stories, TikTok, Shorts | 1080×1920 | `video/explainer-reel-44s.mp4` |
| YouTube, website, LinkedIn, X | 1920×1080 | `video/explainer-landscape-44s.mp4` |

Also written: `audio/explainer-voiceover-44s.m4a` (voice only) and `video/explainer-captions-44s.txt` (caption
timings, for platforms that take separate subtitles).

The script lives in `voiceover.py` (`SCRIPT`). Each line belongs to one scene, and the scene lasts as long as the
line takes to say, rounded to the beat, so editing the words re-times the whole video. The music is the same theme,
ducked under the voice.

| Scene | Voiceover |
|---|---|
| Hook | You save things everywhere. Links, notes, screenshots, code. And when you need them, they're gone. |
| Intro | Meet Stash. One place for everything you save. |
| Canvas | Drop anything onto your canvas. Links, notes, code and images, side by side, arranged the way you think. |
| Ask | Looking for something? Just ask. Stash answers from your own cards, and points to each one, so you know exactly where it came from. |
| Remind | Saved something for later? Add a reminder, and Stash emails you right on time, with the card one tap away. |
| End | Stash is free. Try it today at stash.surajbayas.me |

The voice is macOS text to speech. It uses the best female English voice installed, in this order: Ava (Premium),
Zoe (Premium), the Enhanced versions, then Samantha. The Premium voices sound far more natural; install one at
System Settings → Accessibility → Spoken Content → System voice → Manage Voices → English, then rebuild with
`--explainer`. For a real voice artist, record the six lines and swap them in for `speak()`'s output.

## Concepts

| Key | Headline | Supporting line |
|---|---|---|
| `ask` | Stop digging. **Just ask.** | Stash answers from your own links, notes and screenshots, and points to the exact card. |
| `canvas` | Everything you save, **on one canvas.** | Links, notes, code and images side by side. Drag them where they make sense. |
| `remind` | Saved it for later? **Later is now.** | Set a reminder on any card. Stash emails you right on time, with the card one tap away. |

Video (18 s, with sound): *You saved it somewhere. Now where is it?* → canvas → ask → reminder → end card *Try Stash free*.

## Copy for posting

**Primary text (Reels / feed caption)**

> You saved that link. And that note. And that screenshot. Now where are they?
> Stash puts everything you save on one canvas. Ask a question and it answers from your own cards, pointing at each
> one. Set a reminder and it lands in your inbox on time.
> Free → stash.surajbayas.me

**Short variants**

- Stop digging through your saves. Just ask Stash.
- Your links, notes, code and screenshots on one canvas. Free.
- The read-it-later list that actually reminds you.

**Headline field (link ads, 40 characters max):** `Everything you save, on one canvas` ·
`Ask your saves a question` · `Saved it for later? Later is now.`

**Description field:** `Free. Sign in with Google, X or email.`

**Call-to-action button:** Sign Up (or Learn More).

**LinkedIn launch post** (with `png/linkedin-launch.png` or the landscape explainer)

> I just launched Stash, a canvas for everything you save.
>
> Links, notes, code snippets and screenshots usually end up scattered across bookmarks, chats and notes apps.
> Stash puts them on one visual canvas, then lets you ask questions in plain language. Answers come only from your
> own cards, and every claim points back to the card it came from. Reminders on any card reach your inbox on time.
>
> Under the hood: FastAPI, PostgreSQL with pgvector, a LangGraph retrieval agent with citation checks, and a
> content-safety gate on everything that is stored or sent.
>
> It's free. I'd love your feedback: https://stash.surajbayas.me
